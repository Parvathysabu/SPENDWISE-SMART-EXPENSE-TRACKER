# SPENDWISE-SMART-EXPENSE-TRACKER

\# SpendWise - Smart Expense Tracker



SpendWise is a simple frontend-based expense tracker web application that helps users manage their daily expenses efficiently.



\## Features

\- Add expenses with title, amount, category, and date

\- View all expenses in a clean dashboard

\- Automatic total expense calculation

\- Simple and responsive UI



\## Technologies Used

\- HTML

\- CSS

\- JavaScript



\## Project Purpose

This project is developed to practice frontend development skills including DOM manipulation, event handling, and responsive UI design.



\## How to Run

1\. Download or clone the repository

2\. Open index.html in any browser

3\. Start adding expenses
